# Golden Maid 桌宠素材

本目录包含 InputAtlas 首期键鼠桌宠候选角色“Golden Maid”的单帧状态素材。

## 规格

- 格式：RGBA PNG，真实透明背景；
- 统一画布：`1403 × 1123`；
- 坐标策略：所有帧左上角对齐，不缩放、不拉伸；
- 命名策略：`<state>-<frame>.png`，当前每个状态提供 `01` 静态帧；
- 生成日期：2026-09-02；
- 生成方式：Codex 内置 `image_gen` 生成角色差分，本地 Pillow 仅用于色键转 alpha、边缘去绿色污染和透明画布归一化。

## 状态映射

| 状态 | 文件 | 视觉语义 |
| --- | --- | --- |
| `Idle` | `idle-01.png` | 双眼睁开、轻微微笑；左爪轻放键盘、右爪轻放鼠标，均不表示按下。 |
| `KeyboardLeft` | `keyboard-left-01.png` | 左爪按压键盘左区，配有局部紫色动作符号。 |
| `KeyboardRight` | `keyboard-right-01.png` | 右爪移至并按压键盘右区，鼠标保持未按下。 |
| `KeyboardBoth` | `keyboard-both-01.png` | 双爪同时按压键盘左右区域，表情更兴奋。 |
| `MouseLeft` | `mouse-left-01.png` | 右爪按下鼠标左键，左键区域使用紫色强调。 |
| `MouseRight` | `mouse-right-01.png` | 右爪按下鼠标右键，右键区域使用紫色强调，表情半眯。 |
| `MouseMiddle` | `mouse-middle-01.png` | 右爪按下中键/滚轮，角色使用专注的圆形小嘴表情。 |
| `MouseBack` | `mouse-back-01.png` | 右爪按下后退侧键，后侧按钮使用紫色强调。 |
| `MouseForward` | `mouse-forward-01.png` | 右爪按下前进侧键，前侧按钮使用紫色强调。 |
| `Paused` | `paused-01.png` | 闭眼伏桌休息，带三个紫色睡眠气泡；键盘和鼠标均未按下。 |

鼠标五态仅表达按钮按下，不表达鼠标移动、方向、坐标、轨迹或滚轮方向。应用层应使用明确状态映射加载这些文件，不要根据紫色强调区域反向推断输入数据。

## 角色与画风锚点

- 金黄色超长发和高位侧环发束；
- 白色女仆头饰、深海军蓝/炭色衣袖与头带；
- 紫色蝴蝶结及动作强调色；
- 青绿色双色大眼、星形高光、符号化腮红和小嘴；
- 硬边扁平色块、稀疏内部线条和克制的赛璐璐阴影；
- 夸张长臂与大号连指手套式手掌，保证桌面缩略尺寸下动作可读。

## 最终提示词结构

共用约束：以透明待机母版作为唯一角色与构图锚点，锁定角色身份、发型、服装、配色、画布、键盘、鼠标、鼠标垫和桌面位置；每张差分只改变指定手部接触、对应控件的紫色强调和表情；保持一个角色、两条手臂和两只手；禁止文字、水印、标志、额外肢体、浮空手、鼠标指针、移动轨迹和不透明背景。

变体方向：

- `KeyboardLeft`：左爪压下左侧键区，专注表情；
- `KeyboardRight`：右爪移至右侧键区，左爪保持轻放；
- `KeyboardBoth`：双爪分压左右键区，开心张嘴；
- `MouseLeft`：只强调鼠标左键，明快微笑；
- `MouseRight`：只强调鼠标右键，半眯眼侧笑；
- `MouseMiddle`：只强调中键/滚轮，圆形小嘴；
- `MouseBack`：只强调后退侧键，短暂惊讶；
- `MouseForward`：只强调前进侧键，积极微笑；
- `Paused`：双眼闭合、伏桌休息、抽象睡眠气泡，不使用字母或文字。

## 接入建议

- `PetFrameSet` 启动或首次启用时预加载并冻结位图，输入热路径不要访问磁盘；
- WPF 显示时使用等比缩放，避免将不同状态单独自适应到不同边界框，否则切帧会产生跳动；
- 当前每个状态只有一个成品帧。若后续补充按下/回弹动画，请沿用 `-02`、`-03` 编号并保持相同画布；
- 发布前应按项目素材归属流程登记：原始角色图由用户提供，其生成记录注明使用 Codex 内置 `image_gen`；仓库未包含用于风格参考的第三方图像。
