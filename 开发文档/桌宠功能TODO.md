# InputAtlas 输入桌宠功能 TODO

> 状态：P1 首轮实现完成，待人工冒烟与集成验收
> 创建日期：2026-09-02
> 当前范围：键盘物理按键 + 标准五键鼠标按下/释放
> 明确延期：鼠标移动、坐标、轨迹、移动距离、滚轮动画

## 1. 目标与范围决策

为 InputAtlas 增加一个可选的本地 2D 输入桌宠。桌宠在主窗口隐藏到托盘后仍可单独显示，并根据已有 Raw Input 状态播放轻量按键动画。

本轮目标不是复刻某个现有角色或桌宠程序，而是验证以下最小体验闭环：

1. 用户按下键盘物理按键时，桌宠立即播放左爪、右爪或双爪敲击动画；
2. 用户按下标准鼠标按钮时，桌宠播放相应的鼠标操作动画；
3. 动画不阻塞输入采集，不影响统计正确性，不保存逐事件输入信息；
4. 桌宠可以独立显示、隐藏、拖动、置顶和启用鼠标穿透；
5. 暂停记录、锁屏、睡眠、恢复和退出时，桌宠状态与应用生命周期一致。

### 1.1 本轮纳入范围

- 键盘可观察物理按键的按下与释放；
- 键盘左右手区域映射；
- 同时按键时的单爪、双爪状态；
- 鼠标左键、右键、中键、后退侧键、前进侧键的按下与释放；
- 透明无边框桌宠窗口；
- 显示/隐藏、始终置顶、鼠标穿透、缩放和位置记忆；
- 主窗口隐藏到托盘时继续响应；
- 暂停记录时停止响应并进入暂停状态；
- 原创或许可证明确的本地离线动画素材；
- 细粒度生命周期与性能降级日志，但不记录具体输入事件。

### 1.2 本轮明确不做

- 不读取或响应鼠标相对移动；
- 不读取鼠标绝对坐标、屏幕坐标或点击位置；
- 不记录鼠标轨迹、距离、方向、速度或轮询率；
- 不使用鼠标移动驱动眼睛、头部或身体朝向；
- 不实现拖尾、粒子轨迹或跟随鼠标移动；
- 不实现滚轮方向动画；
- 不实现 Live2D、骨骼动画、三维模型或物理布料；
- 不引入低级键鼠钩子、驱动、管理员权限或独立常驻进程；
- 不联网下载角色、皮肤、动画或音效；
- 不直接复制 Bongo Cat 或其他现有角色的受保护素材。

鼠标移动继续沿用当前产品基线：Raw Input 中没有按钮标志的鼠标移动事件立即忽略，且不得产生日志、对象分配、UI 消息或持久化数据。未来如需加入鼠标移动响应，必须单独评审隐私、8 kHz 高频输入性能、渲染节流和鼠标坐标语义，不自动继承本 TODO 的实施授权。

## 2. 参考图解释

用户提供的参考图只用于表达以下视觉与交互方向：

- 桌宠位于虚拟键盘或桌面后方；
- 左右爪可以分别对应不同键盘区域；
- 角色造型简洁，黑色线稿配合少量强调色；
- 动画重点是“按下时有立即反馈”，不要求复杂连续动作；
- 鼠标区域可以由一只爪执行按钮操作。

参考图不构成以下要求：

- 不要求复刻具体角色轮廓、表情、构图、键盘布局或配色；
- 不要求把临时剪贴板图片加入仓库或发布包；
- 不代表已获得原图、角色、动画帧或音效的再分发授权；
- 不要求桌宠追踪真实鼠标位置。

正式素材应采用 InputAtlas 原创角色，或使用允许修改、打包和商业/非商业再分发且许可证与项目兼容的素材。第三方素材必须登记来源、作者、许可证、修改情况和发布归属说明。

## 4. 建议实现结构

建议新增以下模块，避免将桌宠逻辑耦合到 `MainWindow`：

```text
src/InputAtlas.App/
├─ Pet/
│  ├─ PetWindow.xaml
│  ├─ PetWindow.xaml.cs
│  ├─ PetAnimationController.cs
│  ├─ PetInputMapper.cs
│  ├─ PetFrameSet.cs
│  └─ PetWindowPlacementService.cs
└─ Assets/Pet/
   ├─ idle-*.png
   ├─ keyboard-left-*.png
   ├─ keyboard-right-*.png
   ├─ keyboard-both-*.png
   ├─ mouse-left-*.png
   ├─ mouse-right-*.png
   ├─ mouse-middle-*.png
   ├─ mouse-back-*.png
   ├─ mouse-forward-*.png
   └─ paused-*.png
```

职责约束：

- `PetWindow`：透明窗口、拖动、鼠标穿透、置顶、DPI 和显示状态；
- `PetAnimationController`：维护最新输入状态并推进有限动画帧，不保存输入历史；
- `PetInputMapper`：把稳定 `InputId` 映射为左爪、右爪或鼠标按钮动作；
- `PetFrameSet`：启动或首次启用时预加载并缓存帧，输入热路径不得访问磁盘；
- `PetWindowPlacementService`：保存位置并在显示器变化后约束到可见工作区；
- `App`：创建、显示、隐藏和关闭桌宠，统一管理托盘与应用退出。

## 6. 验收标准

只有同时满足以下条件，首期桌宠功能才可标记完成：

1. 主窗口隐藏到托盘后，桌宠仍能实时响应键盘和五键鼠标按钮；
2. 键盘长按不会因系统连发形成无限动画队列；
3. 快速输入停止后，桌宠能在短时间内回到待机，不继续播放积压动作；
4. 鼠标移动、坐标、轨迹和距离没有进入桌宠事件管线、日志或持久化；
5. 滚轮不触发本轮桌宠动画；
6. 暂停、锁屏、睡眠、恢复和退出不会留下永久按下姿态；
7. 桌宠默认关闭，启用后可通过托盘随时隐藏或调整位置；
8. 鼠标穿透开启时不遮挡其他应用操作；
9. 多显示器或 DPI 变化后桌宠仍处于可见工作区；
10. 所有素材来源和许可证清晰，发布包不包含未获授权的参考图或角色资产；
11. 日志不含具体按键、鼠标按钮、输入顺序或逐事件时间；
12. 现有输入统计、持久化、热力图、暂停/恢复和性能测试无回归。
